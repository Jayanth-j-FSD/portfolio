# Jayanth Reddy - [Portfolio](https://jayanth-reddy-dev.vercel.app/)

Single-page developer portfolio built with React, TypeScript, Vite and Tailwind CSS.

## Edit the content

All text lives in [src/data/content.ts](src/data/content.ts). Replace every `TODO` before sharing the site.

## Run locally

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run lint
```

## Deploy for free

Push this folder to a GitHub repo, then import it on [Vercel](https://vercel.com) or [Netlify](https://netlify.com).
Both detect Vite automatically (build command `npm run build`, output directory `dist`).
Every `git push` redeploys the site.
